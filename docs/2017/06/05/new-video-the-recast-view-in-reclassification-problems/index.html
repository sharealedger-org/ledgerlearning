The Recast View in Reclassification Problems

June 5, 2017

This weeks video continues the series on ugly, hairy monsters, one of which is reclassification problems. This week's episode defines what a "Recast View" looks like from a reclass perspective, wherein data is moved historically, rather than the "Switch View" which simply changes on reclass date.  Episode 68 of Conversations with Kip, the best financial system vlog there is.
