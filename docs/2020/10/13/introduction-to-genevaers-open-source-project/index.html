Introduction to GenevaERS Open Source Project

October 13, 2020

This episode of Conversations with Kip gives an introduction to the IBM Scalable Architecture for Financial Reporting (SAFR) as it was recently contributed to the Linux Foundation's Open Mainframe Project as the GenevaERS Project.

This presentation was made at the Technical Advisor Committee Meeting on July 9th, 2020.
